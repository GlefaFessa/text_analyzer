# Text Analyzer

Веб-приложение для автоматического анализа текстов на русском и английском языках.
Считает ~200 метрик для русского языка и ~300 для английского: от простых счётных
показателей до стилометрии и SEO-аналитики.

## Возможности

Приложение объединяет **8 групп метрик**:

| Группа | Что считает |
|---|---|
| **Basic** | Символы, слова, предложения, слоги, абзацы, средние длины |
| **Lexical** | TTR, hapax legomena, энтропия Шеннона, индекс Симпсона, Yule's K, покрытие частотных списков |
| **Readability** | Флэш, Флэш-Кинкейд, Туманность Ганнинга, SMOG, ARI, Колман-Лиау, LIX, RIX, индекс Оборневой, ruts-метрики |
| **Morphology** | Части речи, падежи, число, род, вид глагола, время, лицо (pymorphy3 + spaCy) |
| **Syntax** | Деревья зависимостей: глубина, зависимости, клаузы, подчинение/сочинение |
| **Stylometry** | ~95 метрик StyloMetrix для русского, ~196 для английского |
| **SEO** | Водность, заспамленность, классическая и академическая тошнота, ключевые слова и облако ключевых слов |
| **Жанры** | Пресеты «Художественная проза», «Научная статья», «Новость», «Юридический», «Разговорный», «Технический» |

## Интерфейс

- Автоопределение языка (кириллица/латиница)
- Импорт текста из файла `.txt`, `.md`, `.docx` или вставка вручную
- Выбор групп метрик и пресетов по скорости или жанру
- Прогресс-бар с пошаговым статусом
- Интерактивные графики (круговые диаграммы, гистограммы, диаграммы, облако слов)
- Справки по каждой метрике с ссылками на Wikipedia
- Экспорт результатов в JSON

## Установка

Требуется **Python 3.12**.


### Клонировать репозиторий
```
git clone https://github.com/GlefaFessa/text_analyzer.git
cd text_analyzer
```

### Создать виртуальное окружение (Windows)
```
python -m venv venv
venv\Scripts\activate
```
### Установить зависимости (≈2.5 ГБ, 30–60 минут)
```
python -m pip install --upgrade pip
pip install -r requirements.txt
```
